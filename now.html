What I'm currently up to

Last updated: November 2026 — DFW, TX

Work

Product test engineer on TI's Jacinto automotive processors: ATE test development on Advantest V93K and Teradyne UltraFLEX Plus, test hardware bring-up, and root cause analysis. Recently wrapped up an eight-month program management apprenticeship on the Sitara MPU line.

Silicon & FPGA

Building a RISC-V computer on a Kintex-7 FPGA with the open-source openXC7 toolchain. Alongside it, I'm designing an IJTAG (IEEE 1687) "fault hunt" test chip, now targeting an early-2027 Tiny Tapeout shuttle to leave time for proper hardening and gate-level sim. Along the way I've got an open pull request to openFPGALoader for a Xilinx Platform Cable USB clone that needs its firmware reloaded after every replug.

CNC

Rebuilding my Milo v1.5 desktop CNC around a new BTT Scylla controller, including a contactor and e-stop circuit for the VFD spindle. Next up: swapping in a replacement toolsetter, then getting back to real cuts.

Homelab

The Proxmox migration is done. These days it's a multi-node cluster with TrueNAS storage, Grafana and Graylog for monitoring, and Home Assistant running the house, including a staged UPS shutdown that powers everything down in order during an outage. Power monitoring now covers per-circuit usage from the main panel and per-outlet wattage from the rack PDU, all in Home Assistant.

Hardware Odds & Ends

Still iterating on the custom DIN-rail relay driver PCB with isolated I/O for Home Assistant. Also learning SolidWorks to round out Fusion 360 and Inventor.
